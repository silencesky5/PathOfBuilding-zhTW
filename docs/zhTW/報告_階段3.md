# POB 台服版：階段 3（介面中文化）報告

日期：2026-11-12　分支：`zhTW`

## 結論

- POB 現在能顯示中文。介面、計算頁、設定頁、提示視窗，以及裝備、詞綴、寶石、天賦，都用**台服客戶端的官方用語**顯示。
- 只改「畫出來的文字」，POB 的計算完全不受影響。兩隻測試角色的匯入結果和階段 1–2 完全一樣（生命 20,854、轉換失敗 0 行）。
- 選項（Options）裡可以隨時切換中文／英文。
- 用自動檢查工具把兩隻角色的每個分頁、每件裝備、每個天賦、每顆寶石的提示視窗都畫過一遍：沒翻到的文字從 **15,333 行降到 48 行**，剩下的大多是 POB 自己重新斷行過的風味文字。

---

## 1. 怎麼用

1. 點 `Work_Space\POE相關\POB台服版\開啟 POB 台服版.lnk` 捷徑開啟（目標是 `PathOfBuilding\runtime\Path{space}of{space}Building.exe`）。不要開開始選單裡原本安裝的官方版，那個沒有中文。
2. 預設就是中文介面。要切回英文：左下 **Options** → 取消勾選 **Chinese interface (繁體中文介面)**。設定會記住。
3. 想改某個用詞：編輯 `src\Data\zhTW\UI.lua`，存檔後在 POB 按 **F5** 重新載入。

---

## 2. 做法

### 2-1 中文字顯示
POB 的繪圖引擎只內建 128 個英文字元的字型，其他字都會畫成 `[U+53F0]` 這種編碼。
- `src\Export\zhTWFont.ps1` 用 Windows 內建的繪圖功能，把中文字畫成兩張字形圖：16 像素給一般文字、32 像素給大字。字型用 **Noto Sans TC**（OFL 開源授權，可以散布）。
- 收錄 5,545 字：遊戲資料和翻譯裡出現過的所有字，加上 Big5 常用字。
- `src\Modules\ZhTWText.lua` 包裝 POB 的文字繪製：英文照舊交給引擎畫，中文從字形圖貼上。
- 提示視窗的自動斷行改成「先翻譯、再斷行」，中文依字元斷行。
- 輸入框（搜尋框、貼上物品文字的框）裡的文字**不翻譯**，維持使用者輸入的原樣；POB 要解析的英文物品文字也因此不受影響。

### 2-2 翻譯來源（依序）
| 來源 | 內容 | 檔案 |
|---|---|---|
| 介面字典 | POB 自己的按鈕、標籤、提示、計算頁、設定頁：3,275 條字串、649 條格式樣板 | `Data/zhTW/UI.lua` |
| 遊戲名稱 | 裝備基底、傳奇、寶石、天賦、職業與昇華 | 階段 1 的對照表反查 |
| 魔法／稀有物品名 | 前後綴名稱來自 Mods.dat（2,939 條），依台服格式「前綴 + 後綴 + 基底」組合 | `Data/zhTW/Affixes.lua` |
| 詞綴 | 英文詞綴先反解成數值，再用台服中文模板寫出。支援數值範圍 `(19-29)%`、多行詞綴的單一行、星團前綴 | `Data/StatDescriptions/zhTW/en`、`tc`（24 個描述檔） |
| 其他遊戲文字 | 技能說明 997、技能名稱 934、寶石標籤 47、風味文字 5,326 行、提醒文字 466、ClientStrings 5,509 條與句型 896 條 | `Data/zhTW/Display.lua` |

介面字典是 6 個子代理依遊戲官方用語對照表（從 ClientStrings 整理的 4,270 條）翻譯的。每一條的顏色碼、格式符號、換行數都自動檢查過，0 條出錯。

### 2-3 驗證
| 檢查 | 結果 |
|---|---|
| 匯入回歸（`zhTWTest.lua`） | 兩隻角色轉換失敗 0 行，生命 20,854／4,358 不變，傳奇詞綴核對不變 |
| 漏網字串（`zhTWCoverage.lua`） | 15,333 → 48 行 |
| 效能 | 開啟中文後每個畫面多 1～5 ms（天賦頁約 +4 ms），不影響流暢度 |

## 3. 已知限制

1. **剩下的英文：**
   - POB 自己斷過行的風味文字，斷行位置和遊戲原文不同，對不上。
   - 少數台服資料裡沒有的專有名詞，例如 Price of Glory、Runegraft 名稱。
   - 程式執行時才拼接出來的句子。這類遇到再補。
2. **只檢查過兩隻角色會用到的畫面。** 下拉選單展開後的清單、彈出視窗、計算頁的詳細拆解，會用介面字典翻譯，但沒有逐一確認。
3. **用詞：** 子代理標記為「自擬、非官方」的詞，例如 Sap＝削弱、Runegraft＝符文移植、Exert＝激發、Recoup＝補償。看到不順的可以直接改 `UI.lua`。
4. **排版：** 中英文寬度不同，個別按鈕或欄位可能需要微調，要在畫面上看過才知道。

## 4. 每季改版後

在階段 1–2 的步驟之外，多做兩件事：
1. 重跑匯出（`zhTWRun.lua`）：會一併更新 Affixes、Display 與顯示用描述檔。
2. 重新產生字形圖：
   ```bat
   powershell -ExecutionPolicy Bypass -File src\Export\zhTWFont.ps1
   ```
3. 跑 `zhTWCoverage.lua`，看「Untranslated lines」有沒有明顯增加。

## 7. 打包給別人用
- 執行 `powershell -ExecutionPolicy Bypass -File src\Export\zhTWPackage.ps1`，會在 repo 的上一層資料夾（`Work_Space\POE相關\POB台服版`）產生 `POB台服版_日期.zip`（約 613 MB）。
- 只打包版本控制中的 `runtime\`、`src\`（不含 `src\Export\` 與測試腳本）和根目錄必要檔案；`src\Settings.xml`（含帳號資料）與 `src\Builds\` 不在版本控制中，不會被包進去。
- 壓縮檔內附「開啟POB台服版.bat」和「使用說明.txt」。
- 打包後的版本是開發模式：不會自動更新（不會被官方版蓋掉中文化），存檔放在解壓縮的資料夾裡。
- 驗證：解壓到含中文與空格的路徑後執行匯入測試，兩隻角色轉換失敗 0 行。
